# InDrive (fka inDriver)

> InDrive is a global mobility and urban-services platform operating a peer-to-peer, user-proposed pricing model across ride-hailing, intercity/city-to-city rides, courier and freight delivery, and financial services. It is expanding into a "super app" for frontier markets. This is an API Evangelist company profile; InDrive publishes no public third-party developer API at this time.
